Roblox Studio Script + UI

GUI am Sitz: Stellwerke · Shop · Creator

Wenn ein Spieler den Sitz benutzt, öffnet sich ein Haupt-GUI. Über „Stellwerke“ kommt eine weitere Liste mit Einträgen wie „Köln-Düsseldorf“.

  • 1
    Script in den Sitz Packe ein Script direkt in den Sitz/Seat. Das Script erzeugt das GUI automatisch für jeden Spieler.
  • 2
    Beim Sitzen öffnet sich das Menü Es erscheinen die Buttons Stellwerke, Shop und Creator.
  • 3
    Stellwerke-Liste Wenn man auf Stellwerke klickt, öffnet sich ein zweites Fenster mit einer Liste. Dort ist beispielhaft Köln-Düsseldorf drin, und beim Klick darauf wird ein Stellwerk geladen.
  • 4
    Wichtig Das „Stellwerk kommen“ ist in diesem Script als Platzhalter umgesetzt. Du kannst dort später deine echte Stellwerk-Funktion einbauen.
Hinweis: In Roblox Studio kannst du den Code direkt in ein normales Script im Sitz einfügen. Für eine echte Server-/Client-Trennung könnte man zusätzlich RemoteEvents nutzen, aber für dein Beispiel ist dieses Script passend.
